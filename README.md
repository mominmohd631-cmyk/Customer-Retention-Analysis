# Customer Retention Analysis

## Project Overview
This project analyzes customer retention and churn using Excel and SQL. The goal is to understand customer behavior and identify patterns related to customer churn and retention.

## Tools Used
- Microsoft Excel
- SQL

## Excel Analysis
- Data analysis
- Pivot Tables
- Pivot Charts
- Dashboard
- Customer retention and churn analysis

## SQL Analysis
- Data filtering
- Aggregation
- GROUP BY and ORDER BY
- Customer churn analysis
- Customer retention analysis

## Dashboard
The Excel dashboard provides a visual overview of customer retention and churn metrics.

## Project Files
- Excel file – Customer retention analysis and dashboard
- SQL file – SQL queries used for analysis
- Dashboard – Excel dashboard screenshot

## Objective
To analyze customer data and identify insights that can help businesses improve customer retention and reduce customer churn.
